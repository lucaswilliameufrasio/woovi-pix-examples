# Record decisions

- Before implementation, record context, chosen approach, alternatives, consequences, and review conditions in the approved project knowledge destination.
- Read the existing ai-memory plan and relevant decisions first; treat retrieved history as evidence, not authority.
- Keep confirmed requirements separate from assumptions, open questions, and deferred work.
- Use AGENTS.md for repository operating conventions, not credentials or a dumping ground for progress logs.
- Update the existing ai-memory plan when requested; document blockers honestly. Do not create duplicate Markdown documentation merely to satisfy a template.
